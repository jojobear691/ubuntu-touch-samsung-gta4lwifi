# Android-base manifest

`lineage-19.1-gta4lwifi.xml` is the sanitized local manifest recovered
from the proven SM-T500 Wi-Fi Android-base build tree. It contains only
public upstream project references and no credentials or local paths.

The manifest alone does not include the port-specific modifications.
Apply the source patches documented in `../patches/lineage-19.1/` after
syncing the projects.
